# How this model was built: Germany transmission 380/220 kV winter evening 2025-11-27 (UnvalidatedAtScale)

These models were generated by Claude Opus 5.5 (Anthropic), working with full access to GridSim's core code base. That access is what allowed generic but detailed models to exist and to be grounded in real, published data from real operators around the world. These models are not approved for anything other than basic demonstrations. They do provide an exceptional starting point for people to expand into a much more detailed system.

General-purpose fidelity only. This is a solvable approximation for one snapshot, never planning grade, and it has not been validated against official studies (hence UnvalidatedAtScale in its name). It was assembled by a private build pipeline using GridSim's solver, from published open data only, and checked with GridSim's own power flow.

## 3. How it was constructed and iterated

Method in brief: a snapshot build. The data the map needs was fetched once; the network was assembled (voltage classes, cuts at the borders, line and cable parameters from standard types, transformer units, plant placement, demand allocation, dispatch, slack); then solved with GridSim. Each round let the solver's findings (reactive shortfalls, overloads, angle spread, islands, fault levels) point at the next data gap. Rules held throughout: no value is changed just because it clears a solver symptom (a value adjusted to solve with no source is tagged synthetic and listed below); every value carries an evidence class (attested, derived, estimated, synthetic); a deeper, better-sourced round is kept even where it looks worse, because it exposes a real data gap; no round was ever overwritten.

## 5. Known gaps

### Known gaps

- No 110 kV network: demand and embedded generation stand for everything below 220 kV; the embedded supply equivalent is one lumped transformer per station.
- No reactive compensation from JAO (excluded by scope); the bus shunts are fixed repairs.
- Phase shifters (21 in JAO) and 380/380 kV units are not modelled: 28 units; their series reactance (about 12 ohm) and angle control are absent, so loop flows through Vierraden, Roehrsdorf, Hamburg/Ost, Diele, Krempermarsch and Wuergau are uncontrolled.
- Busbar splits are not modelled: one bus per station and voltage (JAO 'C1/C2' and 'Abzweig' parts merged).
- Neighbouring grids are fixed boundary injections (energy-charts physical flows at the snapshot): no foreign network, no fault infeed from abroad, so fault levels near the borders are low.
- Generator locations: register coordinates for 1,111 units, district centre (MaStR publishes only the district key) for 774 units; wind, solar and small units are state totals spread by municipality area / population.
- Offshore wind landing weights are recalled export capacities ([VERIFY]).
- Demand is allocated by population only (no industrial load map); load incl. self-consumption 80,671 MW versus modelled public-grid demand.
- GridSim IEC 60909 feeds the fault from every machine in the file at its rating: offline units (not committed, reserve not called) and idle inverters are flagged converterInterfaced / converterFaultCurrentPu 0 here; committed plant feeds at full rating whatever its dispatch; all wind converters feed at GridSim's default k = 1.2 x rated current (German grid code fault-ride-through reactive current).
