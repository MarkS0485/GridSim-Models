# Licensing and attribution

All 36 cases are cleared for public redistribution in this release. The model
databases are offered under the [Open Database Licence 1.0](LICENCE). GridSim
itself is licensed separately.

| Where to look | What it covers |
|---|---|
| [Model catalogue](README.md#models) | Coverage and a link to each model card |
| `models/<case>/ATTRIBUTION.txt` | Credits to retain when sharing a model |
| `models/<case>/BUILD_README.md` | Source records, source terms and how each case was built |
| `models/<case>/provenance.json` | Machine-readable source and element provenance |

Follow the ODbL attribution and share-alike requirements and the applicable
terms for each source. The release clearance covers the published cases.
Original datasets retain their own terms, including the JAO Static Grid Model
terms for the underlying source data.
